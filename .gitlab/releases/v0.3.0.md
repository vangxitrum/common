## 1. TL;DR

aioz-common is one Go module of 31 packages (plus one deprecated alias) that
replaces `aioz-config`, `aioz-logger`, `aioz-stats`, `aioz-template`'s
`internal/utils` and twelve of depin's utility packages. v0.3.0 adds the clients
for the dependencies services share - Postgres, Redis, RabbitMQ, outbound HTTP,
and the backoff between attempts - plus credential handling. Existing consumers
have three breaking changes: `stats/version` moved to `version` (aliases left
behind), `Info.Version` is a `SemVer`, and a `secret`-tagged config field can no
longer carry a default.

---

## 2. Highlights

### One module instead of five sources

- `aioz-config`, `aioz-logger` and `aioz-stats` merged into one module (v0.1.0);
  the service infrastructure in `aioz-template`'s `internal/utils` moved in
  (`apierr`, `cycle`, `lifecycle`, `logging`, `stats/monitor`); twelve depin
  utility packages imported with their history and original package names
  (v0.3.0).
- Where: `gitlab.internal/tuan.quang.tran/aioz-common`
- Surface: one `require` line and one release cycle. The old repositories are
  archived and should no longer be imported.

### Dependency clients: `postgres`, `redis`, `rabbitmq`, `httpclient`, `retry`

- `postgres` and `redis` dial and ping in `Open`, so a wrong address or an
  expired password fails at startup next to its configuration instead of on the
  first request. Timeouts and pool limits are config fields, metrics come
  built in, and each embeds the library's own client, so no command or query is
  wrapped. `postgres` measures connection-acquire latency and tags failures by
  SQLSTATE; `redis` counts `redis.Nil` as a miss, not an error.
- `rabbitmq`: a supervised connection with backoff, topology re-declared on
  every reconnect, per-publish confirms, and a consumer with a bounded worker
  pool, dead-lettering and a drain that loses nothing at shutdown. It replaces
  eight hand-rolled wrappers.
- `httpclient`: an `*http.Client` with timeouts, a real connection pool, a
  redirect policy that refuses https-to-http, a response body cap, bounded-tag
  metrics and a build-stamp User-Agent. Retry is off by default and opt-in per
  call (`httpclient.WithRetry(ctx)`).
- `retry`: exponential backoff with full jitter - `Do` for bounded work, `Loop`
  for supervisors.

### Credentials: `secret`, `jwt`, config secret tags

- `secret.Token` redacts itself in fmt, slog, JSON and SQL; `secret.Hash` is
  what gets stored. Prefixed API keys carry a lookup id, so verification is one
  indexed row; recovery codes use Crockford base32.
- `jwt`: the algorithm is pinned at construction and the header's `alg` is
  never trusted, an expiry is required, and `Ring` rotates keys on `kid`.
- `config`: `secret:"true"` / `secret:"optional"` field tags, and
  `config.CheckSecrets` at startup.

### Build stamp from Go build info: `version`

- Commit, time and dirty flag come from `debug.ReadBuildInfo`, so no Makefile
  `-ldflags` block is needed. A build counts as a release only when it is clean
  and tagged; an untagged build gets `v0.0.0-dev.<unix>.g<commit>`, which sorts
  below every real tag.
- `SemVer` is comparable, `Register` adds a `version_info` series to
  `/metrics`, and `Info.UserAgent` gives outbound calls a common identity.

### Value types that store correctly

- `uuid` (version 7, a comparable `[16]byte`), `currency` (`Amount[U Unit]`, so
  USD and AIOZ cannot be added together; 18 decimals, no floats), `period`,
  `memory` and `date`.
- `uuid`, `period` and `version.SemVer` implement `driver.Valuer` and
  `sql.Scanner`; a zero `period` or `SemVer` stores as `NULL`.

## 3. Added

- **Configuration and logging** - `config` (struct-tag configuration: flags,
  YAML plus environment, a generated default file), `logger` (a `slog.Handler`
  with async dispatch, rotating files, GELF and per-level sampling), `logging`
  (the config layer over `logger`, with a pre-config `Bootstrap` logger).
- **Service lifecycle** - `lifecycle` (start together, close in reverse, dump
  stacks on a shutdown timeout), `cycle` (an interval runner with
  `Trigger`/`TriggerWait`), `apierr` (status, reason slug and cause, with
  `Trace`/`Tags`).
- **Observability** - `stats/debug` (Prometheus metrics, pprof, `/top`,
  `/version/`, `/health`, dynamic log level), `stats/monitor` (process and
  runtime series), `stats/testcontext` (now with `Go`, `Wait` and `Cleanup`).
- **From depin** - `base58`, `context2`, `date`, `errs2`, `leak`, `lrucache`,
  `memory`, `period`, `readcloser`, `signal`, `slices2`, `time2`.
- **Money and ids** (v0.2.0) - `uuid`, `currency`.
- **New in v0.3.0** - `secret`, `jwt`, `redis`, `rabbitmq`, `postgres`,
  `httpclient`, `retry`, `version.SemVer`, `version.Register`,
  `version.Info.UserAgent`.

## 4. Changed

- **`stats/version`** - moved to `version`. `stats/version` remains as
  deprecated aliases, so no import breaks.
- **`version.Info.Version`** - now a `SemVer`, not a `string`. It still
  marshals as a `v`-prefixed string; code that used it as a string needs
  `.String()`.
- **`version` build stamp** (v0.2.0) - derived from Go build info. `Info` gained
  `CommitHash`, `Timestamp` and `Modified` and lost the free-form `Build` string.
  The template's `Info()` / `Current()` accessor is gone; read `version.Build`.
- **`config`** - a `secret`-tagged field may no longer carry `default` or
  `releaseDefault`; `Bind` panics if it does. A placeholder secret in the source
  tree is the password of every deployment that never overrode it.
- **`uuid.UUID.Value`** - writes the canonical string instead of 16 raw bytes.
  `uuid` columns are unaffected; `Scan` still reads both forms.
- **`apierr`** (v0.2.0) - keeps the type and trace helpers; the reason-naming
  policy test was dropped, since a service enforces its own convention.
- **`currency`** - built on `cosmossdk.io/math` instead of cosmos-sdk types:
  2 modules instead of the 73 depin's `AiozCoin` pulled in.

## 5. Fixed

- **`logger`** - a data race in the async handler under concurrent logging, and
  `.With` attributes being dropped by the async handler.
- **`version`** - on Go 1.24+, a build from a modified tree carries `+dirty`,
  which defeated the pseudo-version check and silently dropped a
  `-X buildVersion` stamp on local builds.
- **`version`** - every Makefile-stamped build counted as a release, so
  `devDefault` config tags were unreachable and local builds logged JSON. The
  defaults channel (`Channel()`) is now separate from the stamp and is dev unless
  the build says release.
- **`uuid`** - `Value` sent raw bytes, so a `text`/`varchar` column rejected the
  statement (`invalid byte sequence for encoding "UTF8"`) and `lib/pq` refused a
  `uuid` column.
- **`period`, `version.SemVer`** - unusable as SQL columns (no driver converter
  for a struct), failing at the first query rather than at compile time.
- **`stats` docs** - the `-ldflags -X` examples targeted struct fields, which
  the linker silently ignores.

## 6. Migration notes

- **Imports** - rewrite the old paths:

  | Old import | New import |
  | --- | --- |
  | `aioz-config` | `aioz-common/config` |
  | `aioz-logger` | `aioz-common/logger` |
  | `aioz-stats/...` | `aioz-common/stats/...` |
  | `aioz-common/stats/version` | `aioz-common/version` |
  | `aioz-template/internal/utils/...` | `aioz-common/{apierr,cycle,lifecycle,logging}` |
  | `aioz-depin/internal/memory` (and the other eleven) | `aioz-common/memory` (same package name) |

  The depin packages that already existed here under a different API -
  `lifecycle`, `debug`, `version`, `testcontext`, `cfgstruct`, `grpcerr` - need a
  real reconciliation, not a path rewrite.
- **`version.Info.Version`** - add `.String()` wherever it was used as a string.
- **`-ldflags`** - `-X .../stats/version.Build.X=` becomes
  `-X .../version.buildVersion=`, or drop the block: build info supplies the
  stamp.
- **Secret defaults** - before upgrading, find `secret`-tagged fields with
  `default` or `releaseDefault` (they now panic in `Bind`), move any local value
  to `devDefault` with `releaseDefault:""`, and call `config.CheckSecrets` at
  startup.
- **`uuid` in `bytea` columns** - new rows get the canonical string form; check
  that no reader expects 16 raw bytes.
- Full guide: [`docs/ADOPTING.md`](../../docs/ADOPTING.md).

## 7. Internal

- Every source repository was imported with its history; `git blame` resolves
  to the original commits (README §History shows how to walk the pre-import
  log). Dead code found in the imported depin packages was deleted.
- Dependencies: `blang/semver/v4`, `golang-jwt/jwt/v5`, `zeebo/errs/v2`
  (direct), `redis/go-redis/v9` v9.22.0, `rabbitmq/amqp091-go` v1.14.0,
  `jackc/pgx/v5` v5.10.0, `cosmossdk.io/math` v1.4.0. `testcontainers-go`
  v0.40.0 is test-only and, with module-graph pruning, never enters a consumer's
  build list. `zeebo/errs` v1 was converted away rather than added.
- CI: `lint` (blocking, golangci-lint v2.11.4) then `test` then `integration`.
  The integration job runs the `redis`, `rabbitmq` and `postgres` container
  tests on the runner's docker socket, because the runner is not privileged and
  docker-in-docker cannot start. `AIOZ_REQUIRE_DOCKER=1` turns a skip into a
  failure, the harness fails fast when `DOCKER_HOST` silently falls back to
  another daemon, and the rabbitmq harness retries past a host port another job
  holds.
