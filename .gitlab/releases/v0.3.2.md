## 1. TL;DR

Eight security controls from the OWASP cheat sheets: `clientip`, `ratelimit`,
`password`, `httpsec`, `upload`, `postgres.SortColumns`, log redaction and a
container health check. There is also a jwt key ring loaded from a directory
of PEM files, and new `mail` and `random` packages. Almost everything is
additive, with three exceptions. `logging` now redacts sensitive attributes by
default. `secret.KeyRef` gains a `hint` JSON field. And `httpclient.Retry.Do`
now keeps the first `Idempotency-Key` for every retry.

## 2. Highlights

### Login and account protection: `password`, `ratelimit`, `clientip`

- **`password`** - argon2id storage to OWASP's Password Storage cheat sheet
  and NIST SP 800-63B. The default is 19 MiB, 2 iterations, and `New` refuses
  parameters below OWASP's floor. Hashes are PHC strings, decoded strictly.
  `Verify` costs one derivation on every path, including an unknown account
  (checked against a dummy hash), and compares in constant time. Legacy bcrypt
  hashes verify and report `NeedsRehash`. Passwords are NFC-normalized, and
  `Check` requires at least 15 characters. `MaxConcurrent` caps how many
  derivations hold memory at once.
- **`ratelimit`** - GCRA windows in Redis (`WithRedis`, one atomic Lua script)
  or in memory. A denied request consumes nothing, so hammering a victim's key
  cannot lock them out. A long window behind a short one gives a progressive
  delay, and `Result.RetryAfter` is exact. Keys are hashed, and an IPv6 client
  is keyed by its /64. Every Redis call is bounded by `Timeout`, and a failure
  applies `OnError`: `local` (the default), `open` or `closed`.
- **`clientip`** - the address a request really came from. `X-Forwarded-For`
  is walked from the right past the configured `TrustedProxies`, so a client
  cannot choose the address it is limited and logged by. With no trusted
  proxies, no header is read. `New` refuses `0.0.0.0/0` and `::/0`.
- Surface: `password.Config`, `ratelimit.Config` (`Prefix`, `OnError`,
  `Timeout`, `Capacity`), `clientip.Config` (`TrustedProxies`, `Header`). The
  READMEs have the gin and echo wiring and the login, forgot-password and OTP
  recipe.

### HTTP hardening: `httpsec`, `upload`, `SortColumns`, log redaction

- **`httpsec.Headers`** - sets the OWASP header set before the handler runs, so
  a handler can still override one: a no-HTML CSP, two-year HSTS with
  subdomains, nosniff, `DENY` framing, a strict referrer policy, COOP, CORP, a
  permissions policy and `no-store`.
- **`httpsec.CORS`** - off until origins are configured. Exact origins and
  `https://*.example.com` wildcards match strictly. `NewCORS` refuses `*` with
  credentials, `null`, paths and TLD wildcards. Every preflight gets a 204
  without reaching the handler. Both have a stdlib `Wrap`.
- **`upload.Policy`** - accepts a form file only when its extension and its
  sniffed content name the same allowed type (PNG, JPEG, GIF, WebP). The
  client's `Content-Type` is never read, and SVG and HTML can never be allowed.
  Past `MaxBytes` it fails with `ErrTooLarge` instead of truncating.
  `DisplayName` and `LimitRequest` come with it.
- **`postgres.SortColumns`** - an allowlist for `ORDER BY`, which cannot take a
  bind parameter. An unknown key or direction returns `ErrInvalidSort` (a 400).
- **Log redaction** - `logging.New` and `logging.Bootstrap` log `password`,
  `secret`, `token`, `authorization`, `cookie`, `api_key` and their relatives
  as `[redacted]`, including everything under a group with one of those names.
  Keys are matched exactly after lowercasing and mapping `-` to `_`, so
  `token_count` is untouched. This is a safety net: values inside headers,
  structs and bodies are not inspected.
- **`debug.HealthCommand`** - a `healthcheck` subcommand that GETs `/health`
  on the debug server, for a `HEALTHCHECK` in a distroless image with no shell
  or `curl`. `debug.CheckHealth` does the same check as a function.

### jwt key rotation and token types

- **`jwt.LoadKeyRing(dir, active, opts)`** - reads `<name>.pem` (private) and
  `<name>.pub.pem` (public only) files. It returns a `Signer` for the active key
  and a `Ring` that verifies with every key. The kid is the RFC 7638 thumbprint,
  so replicas agree on it with no coordination. Rotating a key is a three-step
  file change: publish the new key, switch the active name, retire the old key.
  Keys are Ed25519 or RSA of at least 2048 bits. A private key and a public key
  under the same name that do not match is a load error.
- **`jwt.GenerateKey`, `WritePrivateKey`, `WritePublicKey`** - the pieces of a
  `genkey` command. Files get modes 0600 and 0644 and are never overwritten.
  A key name that would not load back (a leading `.`, or ending in `.pem` or
  `.pub`) is refused before anything is written.
- **`jwt.WithType` / `jwt.RequireType`** - stamp and require the `typ` header,
  using `TypeAccessToken` (`at+jwt`, RFC 9068). This stops an ID token or
  refresh token signed by the same key from passing as an access token (RFC
  8725 §3.11). The type is checked before the signature and the claims.
- **`KeyRing.DeriveSecret`** - uses HKDF-SHA256 over the active key to derive a
  symmetric secret, for cookie or CSRF keys. It rotates with the signing key.

### `mail` and `random`

- **`mail`** - one `Sender` interface to replace four services' copies of a
  Resend helper. The `resend` provider retries rate limits, an idempotent
  request still in flight, 5xx responses and transport errors with exponential
  backoff, and sends the same `Idempotency-Key` on every attempt, so a message
  goes out once. Quota exhaustion, any other 4xx and a `Retry-After` over 30s
  are not retried. The
  `log` provider (the dev and test default) records that a mail was not sent.
  With the `resend` provider, an empty API key is a startup error. The package
  also has `ParseAddress` (the HTML email pattern, tightened per OWASP, with a
  `Canonical` form for dedupe), `ParseTemplates` (`html/template` with an
  override directory, which may be a Kubernetes ConfigMap mount) and
  `mailtest.Recorder`. Nothing logs a subject, body,
  address or key.
- **`random`** - unbiased CSPRNG helpers: `Bytes`, `IntN`,
  `String(n, Alphabet)` and `Digits(n)`, with the `Decimal`, `Base62` and
  `Crockford` alphabets. They use rejection sampling and never return an error.
  `Digits` panics below 6 digits (SP 800-63B). `secret` is now built on it.

## 4. Changed

- **`logging.New`, `logging.Bootstrap`** - redact sensitive attributes by
  default (see §2). Before, every value was logged as given.
- **`secret.KeyRef`** - gains a `Hint` field, serialized as `"hint"`. Anything
  that encodes a `KeyRef` to JSON emits one more key.
- **`httpclient.Retry.Do`** - the first attempt's `Idempotency-Key` is now set
  on every retry, overriding whatever `newRequest` builds. Before, a key
  generated inside `newRequest` changed on every attempt.
- **`httpclient` private-network guard** - an `allowed-networks` IPv4 prefix
  now also allows that address in its NAT64 and 6to4 IPv6 forms. Before, the
  block check looked through those forms but the allowlist did not, so an
  IPv6-only host behind NAT64 was refused.
- **`secret`** - random generation now goes through `random`. Output format
  and distribution are unchanged, and `TestAlphabetsMatchRandom` pins the
  Base62 order the checksum depends on. The package doc points at `password`
  for passwords.
- **Dependencies** - `golang.org/x/crypto` v0.43.0 to v0.55.0 and
  `golang.org/x/text` v0.40.0 to v0.41.0, both now direct.
  `github.com/resend/resend-go/v3` v3.10.1 is new. Go stays at 1.25.

## 5. Fixed

- **`httpclient.Retry.Do`** - retrying a `POST` that timed out after the server
  had processed it could be taken as a second request (a double charge), when
  the caller built the `Idempotency-Key` inside `newRequest`. Reported by the
  v0.3.1 review.
- **`httpclient.ParseRetryAfter`** - a `Retry-After` of the largest integer
  overflowed to -1s, which turned "wait forever" into "retry now". It now
  saturates, so `DefaultRetryable` sees it as too long and stops.
- **`httpclient` guard** - see §4: allowed IPv4 networks were refused when
  reached through NAT64 or 6to4 (it failed closed). Reported by the v0.3.1
  review.
- **Security advisories** - the `x/crypto` bump clears ten HIGH advisories
  that trivy flags in `x/crypto/ssh`. govulncheck found none of them reachable
  from this module.

## 6. Migration notes

- **Log queries and dashboards** - a field named `password`, `secret`, `token`,
  `authorization`, `cookie` or `api_key` (or a relative, or anything under a
  group with one of those names) now reads `[redacted]`. If a service
  deliberately logged a non-secret value under one of those names, rename the
  attribute. `logging.Config.Redact` adds more keys.
- **`secret.KeyRef` in API responses** - the JSON gains `"hint"`. Clients with
  strict decoders must accept the new field.
- **API keys** - to show `aioz_...w2Qe` in a dashboard, store `Key.Hint()` when
  the key is minted. The stored hash cannot give it back later.
- **Retry call sites** - nothing to do. A call site that relied on a fresh
  `Idempotency-Key` per attempt was already broken.
- **`debug.HealthCommand`** - pin `debug.addr`. It defaults to a random port,
  and the health check cannot find that.
- **`ratelimit` with Redis** - run the server with `maxmemory-policy
  noeviction`, and give each service its own `ratelimit.Config.Prefix` unless
  they should share one budget.
- **`mail`** - with the `resend` provider, an empty `ResendConfig.APIKey`
  fails at startup on purpose. Dev and test default to the `log` provider.
- **Upgrading the module** pulls `x/crypto` v0.55.0 and `x/text` v0.41.0 into
  the service's `go.mod`. Run `go mod tidy`.

## 7. Internal

- `internal/e2e/owasp_test.go` wires every control into one `net/http` server
  and checks it from outside: brute force, forged `X-Forwarded-For`, the bcrypt
  to argon2id upgrade, redaction, CORS, uploads, headers and `ORDER BY`
  injection.
- The new packages were built test-first, with mutation checks. The ratelimit
  Redis suite and the `mail` retry classification run against real
  counterparts (Redis in docker, a fake Resend server).
- New depguard rule `no-math-rand` in `.golangci.yml`: `math/rand` only in
  tests and the two retry-jitter files.
- `make test-integration` now covers `./ratelimit/...`.
- Stale "retry layer" comments in `httpclient/headers.go` and `redirect.go` were
  corrected.
- **Fixed before tagging, found by the release review** (see the review note).
  Each has a test that failed before the fix:
  - `logger`: `With` under two or more groups wrapped its attributes in one
    group keyed by the joined path (`"auth.password"`), so `RedactAttr` never
    saw the `password` group and logged the value in clear text. It now nests
    one group per name. Tested in `logger` and end to end through
    `logging.New`.
  - `mail.ParseTemplates`: an override directory mounted from a ConfigMap
    failed at startup with `read ..data: is a directory`. Dot entries are now
    skipped, the same rule `jwt.LoadKeyRing` applies.
  - `jwt.WritePrivateKey`: a name ending in `.pub` wrote a private key to
    `<name>.pub.pem`, which `LoadKeyRing` reads as a public key, failing the
    whole ring. Such names are now refused.
  - `httpclient.ParseRetryAfter`: its overflow guard did not compile on 32-bit
    targets (`constant 9223372036 overflows int`), breaking `GOARCH=386` and
    `arm` builds of `httpclient` and everything importing it. The comparison
    is now in int64. The CI `test` job now runs `GOARCH=386 go vet ./...` so
    this cannot ship again.
- `lifecycle.TestSlowShutdownIsReported` was flaky (1 of 30 uncached runs
  failed): it waited for the "slow to stop" warning, then asserted the
  goroutine dump that is logged after it. It now waits on the dump. 200 of
  200 uncached runs pass.
- Verified on 2026-09-14 on `feat/owasp` (`0fe793f`, the same tree as `main`
  `26744d9`) with the fixes above: golangci-lint v2.11.4 found 0 issues,
  `go vet` is clean on amd64 and 386, `go build` passes for 386 and arm,
  `go test -count=1 ./...` passes, and the container suite (`-race`,
  `AIOZ_REQUIRE_DOCKER=1`: redis, rabbitmq, postgres, ratelimit) passes.
