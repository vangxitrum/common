# Release v0.3.1

> 🚀 Two `httpclient` changes, both visible to a caller: a guard against
> server-side request forgery, and retry moved out of the client to the call
> site. Consumer action required: see §6 (Migration notes) before upgrading.

## 1. TL;DR

`httpclient.NewOneShot` now refuses to connect to internal addresses - loopback,
private ranges, the cloud metadata endpoint - so a webhook or callback URL can
no longer reach inside. And the client no longer retries: `WithRetry`,
`WithoutRetry` and the `retry*` config keys are gone, and a call site that
should retry says so with `httpclient.Retry{...}.Do`. Both break existing
callers; §6 has the one-line fixes.

---

## 2. Highlights

### Private-network guard (SSRF)

- A client aimed at a URL someone else supplied can be aimed at
  `http://169.254.169.254/` or any internal service. `NewOneShot` - the client
  for exactly those URLs - now refuses internal addresses by default; `New`,
  for dependencies named in configuration, still allows them.
- The check runs at dial time on the **resolved** address, not the URL's host,
  so DNS rebinding and redirects into the network are refused too: every
  redirect hop is a new dial.
- Blocked: loopback, private, link-local, carrier-grade NAT, IPv6 unique-local
  and site-local, multicast, reserved and documentation ranges, and an internal
  IPv4 address written as IPv4-mapped, NAT64 or 6to4 IPv6.
- Where: `httpclient/guard.go`
- Surface: config keys `private-networks` (`allow` | `block` | empty = the
  constructor decides) and `allowed-networks` (exempt prefixes; setting it turns
  blocking on even for `New`); `ErrBlockedAddress`; metric `http_dial_refused`
  tagged by client and reason.

### Retry is the caller's job

- The retry `RoundTripper` and its per-call context flag are gone. The flag
  failed silently - `WithRetry` on a `POST`, or on a body that could not be
  rewound, did nothing - and it leaked into every call made further down with
  the same context. Every `Do` is now one attempt.
- A call site that should retry uses an explicit policy:

  ```go
  policy := httpclient.Retry{Name: "billing", MaxAttempts: 4}
  resp, err := policy.Do(ctx, billing, func(ctx context.Context) (*http.Request, error) {
      return http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
  })
  ```

- Two plain functions carry the policy: `Retryable(resp, err) bool` decides
  whether to try again, `Wait(attempt, resp, err) time.Duration` how long to
  sleep. `DefaultRetryable`, `RetryableWithin`, `Exponential` (full jitter),
  `Constant` and `RetryAfter` come with the package.
- `Do` builds a fresh request per attempt (so any body is sent whole), drains
  the responses it discards (so the pool survives an incident), skips a wait
  that would outlast the deadline, and returns the last response intact when the
  attempts run out.
- Where: `httpclient/retry.go`
- Surface: metrics `http_retries` and `http_retries_exhausted`, tagged by
  `Retry.Name`.

## 3. Added

- **`httpclient`** - `Retry`, `Retryable`, `Wait`, `DefaultRetryable`,
  `RetryableWithin`, `ParseRetryAfter`, `Exponential`, `Constant`,
  `RetryAfter`, `DefaultMaxAttempts`, `MaxRetryAfter`.
- **`httpclient`** - `Config.PrivateNetworks`, `Config.AllowedNetworks`,
  `ErrBlockedAddress`, and the `http_dial_refused` counter.

## 4. Changed

- **`httpclient.NewOneShot`** - refuses internal addresses by default. It used
  to connect anywhere the URL pointed.
- **`httpclient` guarded transports** - ignore `HTTP_PROXY`. Through a proxy
  the guard would only ever see the proxy's address. `New` is unguarded, and
  keeps using the proxy, unless `private-networks: block` or `allowed-networks`
  is set.
- **`httpclient` retry** - removed from the client. `WithRetry`,
  `WithoutRetry` and `Config.Retry`, `RetryMax`, `RetryWaitMin`,
  `RetryWaitMax`, `RetryNonIdempotent` are gone.
- **`httpclient` retry defaults** - a `POST` or `PATCH` without an
  `Idempotency-Key` still gets one attempt, now unless the call site sets
  `Retry.AllowNonIdempotent`. A `Retry-After` longer than 30s ends the retrying
  (it used to be `RetryWaitMax`); `RetryableWithin` changes the limit.
- **`httpclient` metrics** - `http_retries` and `http_retries_exhausted` are
  tagged by `Retry.Name` instead of the client's name, and the
  `http_retry`, `http_retry_exhausted` and `http_retry_after_too_long` events
  are gone.

---

## 5. Fixed

- **`httpclient`** - a retried request whose body could not be rewound (any
  reader other than `bytes.Reader`, `bytes.Buffer` or `strings.Reader`) was
  silently sent once. `Retry.Do` builds each attempt's request itself, so every
  body is replayable.

---

## 6. Migration notes

- **Retrying call sites** - replace

  ```go
  resp, err := client.Do(req.WithContext(httpclient.WithRetry(ctx)))
  ```

  with `httpclient.Retry{Name: "<dependency>"}.Do(ctx, client, newRequest)`,
  building the request inside `newRequest`. Keep a deadline on `ctx` that covers
  every attempt: with the default wait, three retries can spend up to 7s
  waiting.
- **`WithoutRetry`** - delete it. The client no longer retries anyway.
- **Config files** - delete `retry`, `retry-max`, `retry-wait-min`,
  `retry-wait-max` and `retry-non-idempotent` under every `httpclient` block.
- **Dashboards and alerts** on `http_retries` / `http_retries_exhausted` -
  set `Retry.Name` to the client's name to keep the series continuous. Anything
  built on the removed `http_retry*` events needs moving to the counters.
- **`NewOneShot` to an internal address** - it now fails with
  `ErrBlockedAddress`. Add the prefix to `allowed-networks`, or set
  `private-networks: allow` if the client never sees an outside URL.
- **`NewOneShot` behind `HTTP_PROXY`** - the proxy is no longer used. Set
  `private-networks: allow` if the proxy is required and the URLs are trusted.
- Full guide: [`httpclient/README.md`](../../httpclient/README.md#retrying-is-the-callers-job).

## 7. Internal

- The retry tests were rewritten for the policy API (24 tests); the waits run on
  a `time2` test clock, so none of them sleeps. The guard has its own suite,
  including a host name that resolves inside and a redirect into the network.
- The retry counters moved from the per-client metrics set into `Retry.Do`.
- No dependency changes; `go.mod` is untouched.
- `aioz-template`'s `rate` slice is migrated to `Retry.Do` (separate
  repository).
- The CHANGELOG's v0.3.0 section described the private-network guard, which
  was merged after the tag; it now sits under v0.3.1.
